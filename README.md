目前做了三款游戏
第一款是无限升级，这个游戏的完成度不是很高，虽然整体上并没有什么问题，整个游戏也能跑通，但是也面临着几个问题，首先是美术资源的短缺，其次是中石头和小石头的辨别度不是很高，最后是当玩家所吸附的石头达到一定数量时会出现时而存在，时而不存在的现象
第二款是绳子打结，这个游戏的完成度相比第一款提升了很多，主要是对于几个辅助功能的设置没有bug，关卡也能进行迭代，唯二比较遗憾的是美术资源的短缺，以及绳子样式只停留在简单的直线，虽然能模拟出曲线，但是在立体感上就没有那么强了
第三款是迷宫纪元，这个游戏的完成度是我认为最高的，在关卡可以跑通的情况下，在美术上下了功夫，但是依旧没有找到玩家和目标的素材，所以只能用简单的颜色来代替，除此之外并没有什么问题
