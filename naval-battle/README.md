# 土豆海战棋

移动端竖屏 H5 单机小游戏，基于 `React + TypeScript + Vite` 实现。参考图只用于美术方向，实际功能按 `prd.md` 落地。

## 功能

- 主菜单、难度选择、布阵、对战、结算五个场景
- 10 x 10 双棋盘，玩家与机器人各 3 艘舰船，长度分别为 4 / 3 / 2
- 玩家支持拖动布阵，轻触舰船旋转方向，支持随机布阵
- 简单 / 困难两档机器人
- 命中继续攻击，未命中则切换回合，重复点击已攻击格会提示
- Web Audio 命中 / 击沉音效
- 本地统计与音量设置保存在 `localStorage`

## 启动

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```
