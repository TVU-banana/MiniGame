# 五子棋

一个基于 `React + Vite + Canvas API` 实现的轻量五子棋小游戏，支持本地双人对战、三档本地规则人机、20×20 棋盘，以及由 `Web Audio API` 直接合成的双场景复古 BGM。

本目录下的

## 安装方式

```bash
npm install
```

## 运行方式

```bash
npm run dev
```

启动后在浏览器打开本地开发地址即可开始游玩。首次点击界面后会激活音频上下文。

## 构建方式

```bash
npm run build
```

## 当前已实现功能

* 20×20 棋盘 Canvas 绘制
* 玩家对玩家模式
* 玩家对机器模式
* 新手 / 普通 / 专家三档本地规则人机
* 黑子先手、连五判胜、满盘平局
* 机器回合 250ms - 500ms 思考延迟
* 胜利连线高亮
* 菜单与对局双场景 BGM
* 按钮、落子、胜利音效
* 一键开启 / 关闭全部声音
* 移动端与桌面端自适应布局

## 棋盘规格

* 棋盘大小：`20×20`
* 棋盘总格数：`400`
* 棋子定义：`0 = 空`、`1 = 黑子`、`2 = 白子`
* 不启用禁手规则

## 双场景 BGM 说明

项目内置两套通过 `Web Audio API` 合成的循环 BGM：

* 菜单曲：节奏较缓，偏欢迎与标题画面氛围
* 对局曲：节奏更强，偏紧张与专注对抗氛围

两套 BGM 会根据当前界面自动切换，不会同时播放。

## 三档非 AI 人机策略说明

机器逻辑完全基于本地规则实现，不接入任何 AI、LLM、服务端接口或外部棋力引擎。

* 新手：优先进攻，防守较弱，容易漏掉玩家的延展威胁
* 普通：会优先处理一步必堵点，并在进攻与防守之间保持平衡
* 专家：带有更严格的优先级体系，并加入局部两步推演强化布局能力

核心策略基于以下流程：

1. 先按已有棋群周边 `1~2` 格生成候选落点，避免全盘暴力扫描。
2. 对候选点从横、纵、两条斜线四个方向识别成五、活四、冲四、活三等棋型。
3. 先处理“自己立即获胜 / 对手下一步可胜”等紧急优先级，再比较综合权重。

## 音频生成方式说明

由于项目未使用外部音频素材，BGM 与音效均由 `Web Audio API` 实时生成：

* BGM 使用方波、三角波、锯齿波组合成简短循环旋律与低频节奏
* 按钮音效、落子音效、胜利音效均由短音高包络合成
* 浏览器自动播放限制通过“首次用户交互后激活 `AudioContext`”处理
