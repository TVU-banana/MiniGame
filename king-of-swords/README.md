# 旋转刀刀刀

基于 `Phaser 3 + TypeScript + Vite` 的竖屏 H5 生存动作小游戏。玩家通过左下角虚拟摇杆移动，依靠围绕自身旋转的刀阵自动攻击怪物，在 180 秒内生存即可获胜。

## 功能

- 竖屏单机战斗
- 左下角虚拟摇杆移动
- 自动旋转刀攻击
- 3 种怪物与递增刷怪节奏
- 刀耐久、报废与击杀成长加刀
- 主菜单、设置弹窗、历史记录、结算面板
- `localStorage` 保存设置和最近 10 条战绩
- Web Audio 合成按钮、命中、死亡、胜负等音效与简单 BGM

## 运行

```bash
npm install
npm run dev
```

构建生产版本：

```bash
npm run build
```

## 操作

- 拖动左下角摇杆移动角色
- 刀会自动旋转攻击
- 怪物碰到玩家会造成伤害，玩家受伤后有短暂无敌
- 每把刀有独立耐久，命中怪物会消耗耐久
- 达到击杀阈值后会解锁更多刀位并立即补出新刀

## 目录

```text
src/
├─ app/        # Phaser 应用入口、事件总线、全局配置
├─ audio/      # Web Audio 管理
├─ data/       # 数值配置与 localStorage
├─ entities/   # 玩家、刀、怪物实体
├─ scenes/     # Boot、Menu、Game 三个 Phaser 场景
├─ systems/    # 摇杆、刷怪、刀阵、成长、记录系统
├─ ui/         # HTML/CSS 覆层与界面控制
└─ utils/      # 通用工具
```

## 说明

- 资源采用程序绘制与合成音，方便直接运行，无后端依赖。
- 历史记录按时间倒序保存最近 10 条。
- 若在移动端调试，建议使用浏览器全屏或独立窗口以获得更稳定的触控体验。
