# 占领格子 Demo

基于新版 `prd.md` 从零重建的 Web 2D Demo。

## 运行

直接在浏览器打开 `index.html` 即可。

## 当前实现要点

- `100 x 100` 棋盘
- `1` 名人类玩家 + `2` 名机器人
- 基础移动 `150ms/格`
- 同方向二次输入加速到 `100ms/格`（1.5 倍）
- 允许尾迹自交
- 回到己方领地触发闭环，使用 flood fill 占领封闭区域
- 可吞并敌方领地和敌方尾迹
- 进入敌方尾迹可击杀对方
- 玩家死亡立即结算
- `60s` 倒计时结算
- 主菜单、设置、历史记录、结算弹窗
- 本地 `localStorage` 保存设置与历史记录
